01 / FUNDAMENTOS

¿Qué significa calibrar?

Es establecer la relación entre las indicaciones del instrumento y los valores de referencia correspondientes, bajo condiciones especificadas.

⚖

Patrón de referencia

Es una referencia con un valor conocido y documentación apropiada. Debe ser adecuada al rango y a la resolución del instrumento.

↔

Error de indicación

E = I − Xref

I = indicación del instrumento; Xref = valor de referencia. El signo nos dice si la lectura está por encima o por debajo.

✓

Criterio de aceptación

El error se compara con un límite establecido. Un ejemplo escolar no debe confundirse con una tolerancia universal ni con un certificado.

02 / FORMULARIO VISUAL

Las fórmulas que debes dominar

Usa el valor de referencia y la indicación en las mismas unidades. No intercambies los datos.

1. Error de indicación
E = I − Xref

Mide la diferencia con signo entre lo que marca el equipo y la referencia.

Paso a paso
  1. Identifica la indicación I.
  2. Identifica el valor de referencia Xref.
  3. Haz I menos Xref.
  4. Conserva el signo y la unidad.
Ejemplo: 100.08 − 100.00 = +0.08 g. Es positivo porque marca de más.
2. Corrección estimada
C = −E

Es el valor que, matemáticamente, compensa el error observado.

Paso a paso
  1. Calcula primero E.
  2. Cambia su signo: positivo pasa a negativo y viceversa.
  3. Usa la misma unidad.
Ejemplo: si E = +0.08 g, entonces C = −0.08 g. No significa que el equipo se ajuste solo.
3. Error absoluto
|E|

Expresa cuánto difiere la indicación, sin decir hacia qué lado.

Paso a paso
  1. Toma el error con su signo.
  2. Quita el signo negativo si lo tiene.
  3. Conserva la unidad.
Ejemplo: |−0.08 g| = 0.08 g.
4. Error relativo
Er = |E| / |Xref|

Compara el tamaño del error con el tamaño de la referencia.

Paso a paso
  1. Calcula |E|.
  2. Divide entre el valor absoluto de la referencia.
  3. El resultado no lleva unidad.
Ejemplo: 0.08 / 100.00 = 0.0008. No se usa esta división cuando Xref = 0.
5. Error porcentual
Er% = Er × 100

Convierte el error relativo a porcentaje para facilitar la lectura.

Paso a paso
  1. Calcula el error relativo.
  2. Multiplica por 100.
  3. Agrega el símbolo %.
Ejemplo: 0.0008 × 100 = 0.08 %.
6. Promedio de lecturas
x̄ = (x₁ + x₂ + … + xn) / n

Resume varias lecturas repetidas; no reemplaza el análisis de error ni de incertidumbre.

Paso a paso
  1. Suma todas las lecturas.
  2. Cuenta cuántas lecturas hay.
  3. Divide la suma entre el número de lecturas.
Ejemplo: (100.01 + 100.02 + 99.99) / 3 = 100.0067 g aproximadamente.
03 / INSTRUMENTOS DE MASA

Calibración de una balanza

Una balanza se compara con masas de referencia adecuadas. El comportamiento puede variar según la carga y las condiciones de uso.

1. Revisa

Equipo limpio, instalado de forma estable y cero verificado.

2. Compara

Coloca la masa de referencia con cuidado y espera estabilidad.

3. Calcula

Resta la referencia a la indicación y registra la unidad.

Ejemplo resuelto paso a paso

La referencia vale 100.00 g y la balanza indica 100.08 g.

E = I − Xref
E = 100.08 − 100.00 = +0.08 g
C = −E = −0.08 g
La indicación está 0.08 g por encima de la referencia. La corrección calculada no ajusta físicamente el instrumento.

Factores que debes revisar

  • Vibraciones y corrientes de aire.
  • Temperatura y tiempo de estabilización.
  • Suciedad o manipulación de las masas patrón.
  • Nivelación, cero y ubicación de la carga.
  • Capacidad, resolución y método utilizado.

Las lecturas originales se conservan; una lectura diferente se investiga, no se borra sin justificación.

04 / INSTRUMENTOS ELECTRÓNICOS

Calibración de un multímetro

La referencia eléctrica debe ser adecuada para la función y el rango evaluados. Un solo punto no demuestra el comportamiento de todos los rangos.

V

Voltaje

Se mide en voltios (V). Para medir voltaje, el multímetro normalmente se conecta en paralelo a los puntos de medición.

A

Corriente

Se mide en amperios (A). En un multímetro convencional suele medirse en serie, con el borne y rango correctos.

Ω

Resistencia

Se mide en ohmios (Ω). La medición de resistencia se realiza en un circuito desenergizado, siguiendo el manual.

Seguridad eléctrica

  • Inspecciona puntas, cables y conectores.
  • Selecciona magnitud y rango correctos.
  • Respeta los límites y categoría del instrumento.
  • No midas resistencia en un circuito energizado.
  • No conectes la entrada de corriente directamente a una fuente de voltaje.
Para esta práctica usa datos simulados o una fuente de bajo voltaje aprobada por el docente. No improvises conexiones.
